# Поиск пятен на кадрах MAR2300

Локальный проект на Python для обработки кадров нейтронного детектора. Задача проекта — находить области повышенной интенсивности на фоне шума и, после согласования геометрии с НИИ, выгружать результаты в лабораторных координатах.

## Запуск на Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
mar-spots inspect data/sample.mar2300
mar-spots validate data/frames.jsonl
```

`inspect` показывает размеры, тип исходных отсчётов, минимум, максимум и заголовок. FabIO читает кадр как MAR345. При чтении интенсивность, ориентация и размер кадра сохраняются.

`validate` проверяет, что кадры декодируются, точки лежат в пределах кадров, один кадр встречается один раз, а все кадры одного эксперимента находятся в одной выборке.

## Внутренний формат разметки

JSONL с одной записью на кадр. Путь к кадру можно указать относительно манифеста. Точки заданы как `[x, y]`, где `x` — столбец, `y` — строка, а `[0, 0]` — центр верхнего левого пикселя. Пустой список обозначает размеченный кадр без пятен. Непроверенные кадры в этот манифест включать рано. Импорт разметки НИИ потребуется сопоставить с этими соглашениями.

```jsonl
{"image":"sample.mar2300","experiment":"run-a","split":"train","points":[[115.5,204],[312,400]]}
{"image":"background.mar2300","experiment":"run-b","split":"validation","points":[]}
```

Поддерживаются `train`, `validation` и `test`. В идентификаторе эксперимента нужно объединять зависимые кадры по согласованному с НИИ признаку, например по одной серии съёмки. Файлы с реальными кадрами и разметкой удобно держать в `data/`, которая исключена из Git.

## Нейросетевая основа

`SpotCNN` принимает нормализованные фрагменты кадра размерности `[N, 1, H, W]` и выдаёт логиты для каждого пикселя. `point_target` строит бинарную карту по размеченным центрам с настраиваемым радиусом. `spot_loss` вычисляет взвешенную бинарную кросс-энтропию, чтобы учесть редкость положительных пикселей. Это стартовый вариант для точечной разметки. Нормализацию, размер фрагмента, радиус цели и правила объединения соседних откликов предстоит определить по реальным кадрам.

Модель пока без обученных весов. Для обучения и оценки нужны кадры и полная разметка отдельных серий. Для лабораторных координат и итогового файла нужен проверяемый пример от НИИ. Вопросы собраны в [QUESTIONS.md](QUESTIONS.md).

## Проверки

```bash
python -m unittest discover -s tests
```

Для запуска проверки обучения на CPU установите PyTorch и повторите команду. Без PyTorch тест нейросети пропускается.

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m unittest discover -s tests
```
