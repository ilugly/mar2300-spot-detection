# Поиск пятен на кадрах MAR2300

Локальный проект на Python для обработки кадров нейтронного детектора. Сейчас он читает кадры, пересчитывает координаты заданных точек и выгружает их в формате `.drx`. Автоматический поиск пятен предстоит обучить и проверить на размеченных сериях.

## Запуск на Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
mar-spots inspect data/sample.mar2300
mar-spots validate data/frames.jsonl
```

`inspect` показывает размеры, тип исходных отсчётов, минимум, максимум и заголовок. FabIO читает кадр как MAR345. При чтении интенсивность, ориентация и размер кадра сохраняются.

`validate` проверяет, что кадры декодируются, точки лежат в пределах кадров, один кадр встречается один раз, а все кадры одного эксперимента находятся в одной выборке.

## Проверка геометрии и выгрузка DRX

Пример ниже использует присланную папку в «Загрузках». Команда выгружает пять точек, вручную выбранных на кадре Ni в MVView.

```bash
archive="$HOME/Downloads/Архив WinRAR"
mkdir -p runs
mar-spots export-drx "$archive/Ni_0Theta_220Dist_1800Exp_001.mar2300" runs/ni.drx \
  --offset-mm 0 -1.5 \
  --point 1150 1150 --point 1152 2296 --point 1182 10 --point 2295 1153 --point 9 1120

mar-spots inspect-drx "$archive/arctit" "$archive/arctit/arktit_.drx" > runs/arctit.json
```

- В `export-drx` координаты берутся из MVView. Точка `1 1` соответствует нижнему левому пикселю. Четвёртый столбец содержит значение этого пикселя, как в примере Ni. Для повторного запуска укажите новое имя выходного файла.
- `--offset-mm` задаёт поправки, которые прибавляются к координатам на детекторе. Для Ni пара `0 -1.5` получена сверкой пяти точек с выгрузкой MVView. Правило расчёта этих поправок по комментариям `delta` и `detzero` нужно уточнить у НИИ. Для серии `arctit` подошли нулевые поправки, это значение по умолчанию.
- `inspect-drx` сопоставляет строки DRX с кадрами одной серии по среднему углу φ, возвращает точки в координатах массива `[столбец, строка]` и сравнивает пересчитанные векторы отражения с исходными. Пустой список здесь означает, что в DRX нет строки для этого кадра. Полнота разметки проверяется отдельно.
- Геометрия проверена при нулевых χ и ω на двух наборах с положениями детектора `TWOTHETA=0°` и `70°`. Понадобится дополнительный контрольный кадр для поддержки ненулевых χ и ω.

## Внутренний формат разметки

JSONL с одной записью на кадр. Путь к кадру можно указать относительно манифеста. Точки заданы как `[x, y]`, где `x` — столбец, `y` — строка, а `[0, 0]` — центр верхнего левого пикселя. Пустой список обозначает размеченный кадр без пятен. Непроверенные кадры в этот манифест включать рано. Импорт разметки НИИ потребуется сопоставить с этими соглашениями.

```jsonl
{"image":"sample.mar2300","experiment":"run-a","split":"train","points":[[115.5,204],[312,400]]}
{"image":"background.mar2300","experiment":"run-b","split":"validation","points":[]}
```

Поддерживаются `train`, `validation` и `test`. В идентификаторе эксперимента нужно объединять зависимые кадры по согласованному с НИИ признаку, например по одной серии съёмки. Файлы с реальными кадрами и разметкой удобно держать в `data/`, которая исключена из Git.

## Нейросетевая основа

`SpotCNN` принимает нормализованные фрагменты кадра размерности `[N, 1, H, W]` и выдаёт логиты для каждого пикселя. `point_target` строит бинарную карту по размеченным центрам с настраиваемым радиусом. `spot_loss` вычисляет взвешенную бинарную кросс-энтропию, чтобы учесть редкость положительных пикселей. Это стартовый вариант для точечной разметки. Нормализацию, размер фрагмента, радиус цели и правила объединения соседних откликов предстоит определить по реальным кадрам.

Модель пока без обученных весов. Для обучения и оценки нужны кадры и полная разметка отдельных серий. Оставшиеся вопросы собраны в [QUESTIONS.md](QUESTIONS.md).

## Проверки

```bash
python -m unittest discover -s tests
```

Для запуска проверки обучения на CPU установите PyTorch и повторите команду. Без PyTorch тест нейросети пропускается.

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m unittest discover -s tests
```
